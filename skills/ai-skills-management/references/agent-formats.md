# Agent Formats Reference

Each AI tool defines custom agents (subagents) with its own file format. An agent from
the central folder must be **converted** to the target tool's format before installing
it; only when source and target formats are the same can the file be linked.

---

## 1. Detect the Source Format

Read the file's frontmatter and classify it:

| Signal                                                                                                   | Source format         |
| -------------------------------------------------------------------------------------------------------- | --------------------- |
| File ends in `.agent.md`                                                                                 | Copilot               |
| `tools` is a YAML list of `group/tool` names (`read/readFile`, `search/codebase`) or tool sets (`edit`)  | Copilot               |
| `model` looks like `Model Name (vendor)` (e.g. `Claude Sonnet 4.6 (copilot)`) or is a list               | Copilot               |
| Copilot-only keys: `handoffs`, `argument-hint`, `target`, `user-invocable`, `agents`                     | Copilot               |
| `.md` in an `agents/` folder, `tools` is a comma-separated string of PascalCase names (`Read, Grep`)     | Claude                |
| `model` is `sonnet`, `opus`, `haiku`, `fable`, `inherit` or a `claude-*` ID                              | Claude                |
| Claude-only keys: `permissionMode`, `disallowedTools`, `maxTurns`, `skills`, `memory`, `isolation`       | Claude                |
| `mode: primary\|subagent\|all` or a `permission:` map                                                    | OpenCode              |
| `.toml` with `developer_instructions`                                                                    | Codex                 |
| `kind: local\|remote`, `max_turns`, `timeout_mins`, snake_case tools (`read_file`)                       | Gemini                |

If signals conflict or none match, show the frontmatter to the user and ask which format
it is. Never guess silently.

The **body** (Markdown below the frontmatter) is the system prompt in every format and is
kept as-is. Only the frontmatter is translated.

## 2. Target Formats

### Claude Code — `.claude/agents/<name>.md`

```markdown
---
name: code-reviewer
description: When Claude should delegate to this agent.
tools: Read, Grep, Glob, Bash
model: sonnet
---

<body>
```

- `name` and `description` are required. Use a lowercase-hyphen slug for `name`
  (no `:`, cannot start with `-`).
- `tools`: comma-separated string. Omit it to inherit every tool.
- `model`: `sonnet`, `opus`, `haiku`, `fable`, `inherit`, or a full `claude-*` model ID.
  Omit to inherit.
- Unknown keys are ignored, but drop them anyway to keep the file clean.
- VS Code Copilot also reads `.claude/agents/` in this format.

### GitHub Copilot — `.github/agents/<name>.agent.md`

```markdown
---
name: Code Reviewer
description: Shown as placeholder text in chat.
tools: ['read', 'search', 'edit', 'execute']
model: Claude Sonnet 4.6 (copilot)
---

<body>
```

- All keys are optional; `name` defaults to the file name.
- `tools`: YAML list of tools or tool sets (`read`, `search`, `edit`, `execute`, `web`,
  `agent`, `todo`) or `group/tool` names. Unknown tools are ignored.
- `model`: `Model Name (vendor)` string or a prioritized list.

### OpenCode — `.opencode/agents/<name>.md`

```markdown
---
description: When to use this agent.
mode: subagent
permission:
  edit: deny
  bash: ask
  webfetch: deny
---

<body>
```

- The **file name** is the agent name; there is no `name` key.
- `description` is required. Use `mode: subagent` for agents converted from other tools.
- Restrict tools through `permission` (`allow` / `ask` / `deny` per key: `read`, `edit`,
  `glob`, `grep`, `list`, `bash`, `task`, `webfetch`, `websearch`, `todowrite`, `skill`…).
  `tools` is deprecated — do not generate it.
- `model` uses `provider/model-id` (e.g. `anthropic/claude-sonnet-...`). Omit it unless
  the user gives one.

### Codex — `.codex/agents/<name>.toml`

```toml
# Generated by ai-skills-management from C:\AI-Skills\agents\code-reviewer.agent.md
name = "code-reviewer"
description = "When Codex should use this agent."
sandbox_mode = "read-only"
developer_instructions = '''
<body>
'''
```

- One agent per file. `name`, `description` and `developer_instructions` are required.
- Put the body in a TOML **literal** multi-line string (`'''`) so backslashes and quotes
  are not escaped. If the body itself contains `'''`, use a basic string (`"""`) and
  escape `\` and `"""`.
- There is no per-tool list. Map tool restrictions to `sandbox_mode`: `read-only` when
  the source agent has no edit/write tools; otherwise omit it (inherits the session).
- Optional: `model`, `model_reasoning_effort`. Omit `model` unless the source names an
  OpenAI model.
- Codex only runs subagents when the user explicitly asks for them; mention this in the
  summary.

### Gemini CLI — `.gemini/agents/<name>.md`

```markdown
---
name: code-reviewer
description: When Gemini should delegate to this agent.
tools:
  - read_file
  - grep_search
  - glob
  - run_shell_command
---

<body>
```

- `name` (lowercase letters, digits, `-`, `_`) and `description` are required.
- `tools`: YAML list of Gemini tool names. Omit to inherit all tools.
- Optional: `model` (omit to inherit), `temperature`, `max_turns`, `timeout_mins`.
- Subagents are enabled by default; they are disabled if `experimental.enableAgents`
  is `false` in `settings.json`. Warn the user if that setting is found.

## 3. Tool Mapping

Map each source tool to the target. Tools with no equivalent are **dropped**, and the
summary lists what was dropped.

| Capability        | Copilot                                                   | Claude          | Gemini                          | OpenCode permission | Codex sandbox |
| ----------------- | --------------------------------------------------------- | --------------- | ------------------------------- | ------------------- | ------------- |
| Read files        | `read`, `read/readFile`, `read/viewImage`                 | `Read`          | `read_file`, `read_many_files`  | `read`              | —             |
| Text search       | `search`, `search/textSearch`, `search/codebase`          | `Grep`          | `grep_search`                   | `grep`              | —             |
| Find files        | `search/fileSearch`                                       | `Glob`          | `glob`                          | `glob`              | —             |
| List directory    | `search/listDirectory`                                    | `Glob`          | `list_directory`                | `list`              | —             |
| Symbol usages     | `search/usages`                                           | `LSP` or `Grep` | `grep_search`                   | `lsp`               | —             |
| Diagnostics       | `read/problems`                                           | `LSP`           | —                               | `lsp`               | —             |
| Edit files        | `edit`, `edit/editFiles`                                  | `Edit`          | `replace`                       | `edit`              | writes        |
| Create files      | `edit/createFile`, `edit/createDirectory`                 | `Write`         | `write_file`                    | `edit`              | writes        |
| Run commands      | `execute`, `execute/runInTerminal`, `execute/awaitTerminal`, `execute/createAndRunTask` | `Bash` (+ `PowerShell` on Windows) | `run_shell_command` | `bash` | —   |
| Git changes       | `search/changes`                                          | `Bash`          | `run_shell_command`             | `bash`              | —             |
| Fetch URL         | `web`, `web/fetch`                                        | `WebFetch`      | `web_fetch`                     | `webfetch`          | —             |
| Web search        | —                                                         | `WebSearch`     | `google_web_search`             | `websearch`         | —             |
| Subagents         | `agent`, `agent/runSubagent`                              | `Agent`         | —                               | `task`              | —             |
| Todo list         | `todo`                                                    | `TodoWrite`     | `write_todos`                   | `todowrite`         | —             |
| Notebook          | `read/getNotebookSummary`, `edit/editNotebook`            | `NotebookEdit`  | —                               | —                   | —             |
| Terminal context  | `read/terminalSelection`, `read/terminalLastCommand`      | — (drop)        | — (drop)                        | —                   | —             |
| Search view results | `search/searchResults` (VS Code Search panel)           | — (drop)        | — (drop)                        | —                   | —             |
| MCP server tools  | `<server>/*`                                              | `mcp__<server>__*` | `mcp_<server>_*`             | —                   | —             |

**Reverse direction** (Claude → Copilot): use the Copilot tool sets (`read`, `search`,
`edit`, `execute`, `web`, `agent`, `todo`) rather than individual tool names.

**OpenCode:** start from `read`/`grep`/`glob`/`list` = `allow`; set `edit`, `bash`,
`webfetch`, `websearch`, `task` to `allow` only if the source has that capability,
otherwise `deny`.

If the source has **no** `tools` key, it inherits everything: omit `tools` in Claude and
Gemini, omit `permission` in OpenCode, omit `sandbox_mode` in Codex.

## 4. Model Mapping

Never invent a model ID. Keep the model only if the target can run that family.

| Source model                         | Claude      | Copilot                    | Gemini     | OpenCode / Codex |
| ------------------------------------ | ----------- | -------------------------- | ---------- | ---------------- |
| Contains `Opus`                      | `opus`      | keep as-is                 | omit       | omit             |
| Contains `Sonnet`                    | `sonnet`    | keep as-is                 | omit       | omit             |
| Contains `Haiku`                     | `haiku`     | keep as-is                 | omit       | omit             |
| Contains `Gemini`                    | omit        | keep as-is                 | keep ID    | omit             |
| Contains `GPT` / OpenAI model        | omit        | keep as-is                 | omit       | Codex: keep ID   |
| `sonnet` / `opus` / `haiku` (Claude) | keep        | omit (picker decides)      | omit       | omit             |
| `inherit` / absent / list            | omit        | keep / omit                | omit       | omit             |

"Omit" means the agent uses the session's current model.

## 5. Name Mapping

Derive a slug from `name` (or the file name): lowercase, spaces and `_` → `-`, remove
other characters. `Code Reviewer` → `code-reviewer`. Use the slug for the destination
file name in every target, and as `name` in Claude, Gemini and Codex.

---

## 6. Link vs. Convert

| Source format = target format? | Install as                                                                         |
| ------------------------------ | ---------------------------------------------------------------------------------- |
| Yes                            | Link (symlink, or hardlink/copy fallback) — stays in sync with the central folder  |
| No                             | **Converted copy** — never link; the target would get a format it does not read    |

Converted copies do not stay in sync. Add a provenance comment so they can be recognized
and regenerated:

- Markdown targets: first line inside the frontmatter
  `# Generated by ai-skills-management from <source path>` (YAML comment, ignored by tools)
- Codex: TOML comment on the first line

Re-running the installation for the same agent regenerates the copy. When listing or
removing, a file with this comment is a **managed** artifact.

## 7. Conversion Report

After converting, show what changed per target:

```
code-reviewer.agent.md  (Copilot format)
  → .claude/agents/code-reviewer.md   [converted copy]
      name:  Code Reviewer → code-reviewer
      model: Claude Sonnet 4.6 (copilot) → sonnet
      tools: 17 Copilot tools → Read, Grep, Glob, LSP, Bash, Agent
      dropped: read/terminalSelection, read/terminalLastCommand
```

Ask for confirmation before writing if anything was dropped or mapped with a fallback
(e.g. `search/usages` → `Grep`).
